# Research paper deployment

The site is static and can be served from the repository root with GitHub Pages.

1. Confirm the verified `work/outputs/capstone_metrics.json` receipt is present.
2. Serve locally with `python -m http.server 8000`, then open `http://localhost:8000/paper/`.
3. Check the results table, mobile layout, links, and acknowledgments.
4. After explicit approval, enable GitHub Pages for the `main` branch and repository root.
5. Verify the direct `/paper/` URL in a private browser window.
6. Only then put that exact URL, as one line, in `submission/paper_url.txt`.

The paper contains the verified aggregate results. Deployment still requires explicit approval.
